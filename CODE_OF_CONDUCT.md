# Code of Conduct

This is a small, personal-use project. Be respectful and constructive in
issues and pull requests — assume good faith, keep feedback about the code,
and skip the hostility.

For anything this short document doesn't cover, this project follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. Conduct concerns can be raised by opening an issue or
contacting the repository owner directly.
